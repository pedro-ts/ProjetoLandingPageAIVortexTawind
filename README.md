# AIVortex Landing Page

Landing page responsiva desenvolvida como projeto de estudo, com foco em aprender e praticar **Tailwind CSS**, responsividade e animações no front-end.

🔗 **Acesse o projeto online:**  
https://pedro-ts.github.io/ProjetoLandingPageAIVortexTawind/

## Sobre o projeto

Este projeto foi criado principalmente com o objetivo de estudar e colocar em prática o uso do **Tailwind CSS**.

Foi a minha primeira vez utilizando Tailwind em um projeto, então aproveitei o desenvolvimento da landing page para entender melhor como funcionam as classes utilitárias, responsividade, espaçamentos, cores, gradientes, efeitos de hover e organização visual sem precisar escrever grandes quantidades de CSS tradicional.

Durante o desenvolvimento também utilizei a biblioteca **AOS (Animate On Scroll)** para adicionar animações aos elementos conforme o usuário navega pela página.

Essa foi uma das partes que mais gostei de conhecer durante o projeto, porque percebi como bibliotecas de animação podem facilitar bastante o desenvolvimento no dia a dia. Com poucas configurações é possível adicionar efeitos visuais interessantes sem precisar criar todas as animações manualmente com CSS ou JavaScript.

## AOS - Animate On Scroll

Neste projeto utilizei a biblioteca **AOS (Animate On Scroll)** para adicionar animações em diferentes elementos da página.

Com ela foi possível criar efeitos como:

- Fade
- Zoom
- Flip
- Animações ativadas durante o scroll
- Controle da duração das animações

Achei a biblioteca extremamente útil porque permite criar uma experiência visual mais interessante sem precisar desenvolver todas as animações manualmente.

Foi uma ferramenta que gostei bastante de conhecer e que pretendo utilizar novamente em outros projetos quando fizer sentido.

## Objetivo

O principal objetivo deste projeto não foi apenas criar uma landing page, mas utilizar o desenvolvimento como uma forma de aprendizado.

A ideia foi sair um pouco do CSS tradicional e experimentar uma nova forma de estilização utilizando Tailwind CSS, além de conhecer ferramentas que podem tornar o desenvolvimento front-end mais rápido e produtivo.
